# 严格派中枢规则（唯一口径）

> 状态：L1/L2 规则定稿；L3（真多级别、区间套、跨周期）不在本文范围。
> 本文是严格派中枢的**唯一规范文本**；`PLAN.md`、代码注释、proto 注释只引用本文，不复制公式。

## 1. 级别与对象

| 级别 | 构成 | 说明 |
| --- | --- | --- |
| 1 | 段中枢 | 构成单元 = 段；未确认段参与时标虚 |
| 2 | 9 段升级 / 扩张 | 3 个 3 段组，或 2 个同级别中枢合并 |
| 3 | 级别 2 扩张 | L2 封顶，不再递归 |

`StrictPivot` 字段：`level/kind/is_sure/start_index/end_index/upper/lower/middle/gg/dd/move_count/move_start/move_end`。
`move_start/move_end` 是构成段在 `StrictPivotSet.segments` 中的闭区间下标（9 段升级同样指向构成段）；`move_count` = 构成单元数（段数 / 3 段组数 / 合并的子中枢数），级别 3 扩张沿用起始子中枢的段区间。

## 2. 段中枢（级别 1）

**成枢条件**：连续 3 个段，每段先满足「完成次级别走势」门槛，再判 `min(段包络高) >= max(段包络低)`。

- **段包络** = 段内全部构成笔 `get_high()` 的最大值 / `get_low()` 的最小值，统一由 `seg_envelope(bis, seg)` 计算（严格中枢与 `objects.rs::map_segment` 共用）。
- **门槛**：段内笔序列能形成至少 1 个笔中枢，或段笔数 ≥ `MIN_SEG_BI_LEN`（模块常量，默认 5）。不满足的段不参与三元组，本轮跳过并后移扫描。
  - 原因：段方向交替、相邻段共享端点，使「3 段重叠」近乎恒真（仅深跌破位/弱反弹不成立）；不加门槛则中枢数量≈段数/常数，「过滤笔中枢噪声」的卖点不成立。

**区间**：

- `ZG = min(段包络高)`、`ZD = max(段包络低)`，前 3 段确认后固定，延伸不改。
- `GG = max(段包络高)`、`DD = min(段包络低)`，随延伸更新；`ZZ = (ZG + ZD) / 2`。
- 允许 `ZG == ZD`（零宽度），不过滤；所有重叠判定统一 `>=` 记相交。

**延伸与结束**：

- 「有交集」= 段包络 `[low,high]` 与 `[ZD,ZG]` 有公共点，即 `high >= ZD && low <= ZG`。
- 有交集（含跨过整个区间的突破段 `low < ZD && high > ZG`）→ 并入、更新 `GG/DD`。
- 完全在区间外（`high < ZD || low > ZG`）→ 中枢在该段之前结束；该段是**离开段**，不属于中枢；下一轮从离开段之后扫描。
- 段归属唯一：每段只能属于一个中枢或作为某一中枢的离开段。

## 3. 9 段升级（级别 2）

- `move_count >= 9` 时取前 9 段分 `G1/G2/G3`，每组 3 段。
- **统一口径**：每组须「自身合法」（组内 `GZ = min(三段包络高) >= GD = max(三段包络低)`）且「与级别 2 当前区间相交」。级别 2 区间由 `G1` 的 `[GD,GZ]` 初始化，随 `G2/G3` 收缩 `ZG2 = min(GZ_i)`、`ZD2 = max(GD_i)`；`ZG2 < ZD2` 则升级失败。
- `GG/DD` = 9 段总 `max/min`；`move_count` = 3 段组数。
- 超过 9 段：每多 3 段成组，自身合法且与级别 2 区间相交则并入，否则停止；剩余 1–2 段留在级别 1。
- **首个 9 段升级失败**（`ZG2 < ZD2`）时，该中枢不再升级，全部段留在级别 1 继续延伸。
- 9 段升级为常见严格派工程规则，非原文逐字定义。

## 4. 扩张（级别 2/3）

**双条件**（相邻同级别中枢须同时满足）：

1. 波动区间重叠：`prev.GG >= curr.DD && curr.GG >= prev.DD`；
2. 核心区间重叠：`prev.upper >= curr.lower && curr.upper >= prev.lower`。

只有条件 1 会把「核心区完全不同、仅被毛刺撑宽」的中枢合并（如 A 核心 `[18,20]`/`GG=100`/`DD=5`，B 核心 `[88,90]`），再叠加「高级别隐藏低级别」会让 A 凭空消失，故加条件 2。

**合并区间**：`upper = min(prev.GG, curr.GG)`、`lower = max(prev.DD, curr.DD)`、`gg = max(prev.GG, curr.GG)`、`dd = min(prev.DD, curr.DD)`。
（`upper/lower` 用 GG/DD 求交是「波动区间扩张」的定义；与 §3 用子中枢 `ZG/ZD` 是不同概念。）

**终止约束**（三者同时）：`move_count <= MAX_EXPANSION_MEMBERS`（默认 4）；合并后 `end_index - start_index <= MAX_EXPANSION_SPAN_BARS`（默认 250）；只合并相邻且中间无其它同级中枢的链。超过任一即停止，保留为多个同级中枢。

**升级流水线（互斥）**：先出全部 level1 → 对 `move_count >= 9` 者做 9 段升级（升级后不再参与扩张）→ 只在未升级的 level1 之间扩张 → level3 只在 level2 之间扩张一次。对象层与显示层都按此去重。

## 5. 虚中枢与确认

- `is_sure = true` 当且仅当所有构成段 `is_sure = true`，且不含窗口起点切出的首段（窗口伪影，一律标虚、默认不绘制，仅对象/调试保留）。
- 中枢是否结束不影响确认（已结束但含未确认段仍为虚）。
- **`is_sure` 非稳定**：尾部完成笔可能被新 K 线破坏/合并而重构，重算可能改判；「`is_sure=true`」是当前快照认定，不保证不重绘。
- 未确认段参与即虚，图上灰色 / 负编码表示。
- 已知后果：尾部未完成段恒 `is_sure=false`，最新中枢通常为虚、407/408 在近端不出现，只能事后回看。

## 6. 段级三买三卖（407/408）

只对 `is_sure=true` 的级别 1 段中枢计算，每中枢最多一个三买、一个三卖；虚中枢不产出。

**离开段方向**：因「有交集即延伸」会吸收突破段，离开段的实际方向与离开方向相反：

- 向上离开 → 离开段是**下跌段**（整体在 ZG 上方，`low > ZG`），其终点即回抽低点；
- 向下离开 → 离开段是**上涨段**（整体在 ZD 下方，`high < ZD`），其终点即反抽高点。

**锚点**：

- 三买：向上离开段终点 `> ZG`，锚在该终点；其后向上段低点仍 `> ZG` 作确认，锚点不回移。
- 三卖：向下离开段终点 `< ZD`，锚在该终点；其后向下段高点仍 `< ZD` 作确认，锚点不回移。
- 离开段与确认段都须 `is_sure=true`；任一后续段回到 `[ZD,ZG]` 即失败，不补第二次。
- 级别 2/3 的三买三卖留 L3。

**锁定用例**：中枢 `[100,110]` / 上 `105→130`（延伸段）/ 下 `130→115`（离开段，回抽低点 115）→ 三买锚 **115**，不是随后上涨段顶部。

## 7. 通道编码

| func_id | 含义 |
| --- | --- |
| 305/306/307 | 每 bar 唯一可见中枢的 `ZG/ZD/ZZ`，区间外 0；虚中枢取负 |
| 308 | 边界码（见下） |
| 407/408 | 段级三买 / 三卖锚点价格 |

> 305–307 的符号即 `is_sure`：公式用 `ABS` 取价、用正负判虚实，保证整段矩形都能按确认状态着色。

**308 = `level*10 + edge`**：区间内 `edge=0`（只带级别，供整段上色），左右界 `edge=1/2`；实为正、虚为负、`0` 表示无中枢。
- 实中枢：区间内 `10/20/30`，边界 `11/12`、`21/22`、`31/32`；虚中枢取负。
- 公式解码：`实 := v > 0; 虚 := v < 0; level := INTPART(ABS(v)/10); edge := ABS(v) - level*10;`
- 负值只用于条件比较，不可直接作 `DRAWICON/STICKLINE` 的价格参数。

**每 bar 至多一个可见中枢**，可见优先级：`is_sure`（实优先）> `level`（高优先）> `move_count`（大优先）> `start_index`（靠后优先）。即实高级隐藏时间重叠的低级，但**实低级优先于虚高级**（虚高级不覆盖已确认低级）。被淘汰者仍保留在对象 `strict_pivots`。

**多级同 bar**：被隐藏/淘汰的中枢不写 305–308；`build_strict_channel` 沿用「先左后右、已占升级为共用」，并要求 display 集内两中枢不共享边界 bar。

## 8. 与原文/常见实现的差异

- 构成单元：工程上取「段」，非严格递归的次级别走势；并加「完成次级别走势」门槛弥补。
- 9 段升级：常见工程规则，非原文逐字。
- 延伸：严格解释「完全离开即结束」，不做「离开后返回再并入」。
- 扩张：保留 GG/DD 波动区间口径，但加核心区间双条件与链长/跨度上限，避免吞并整段历史。
- 级别 3 只做 level2 扩张，不做 27 段升级。

## 9. 窄中枢判读（用户侧）

窄 = 该级别重叠区窄、波幅小，不是强弱信号本身。是否有效看四点：级别（段中枢比笔中枢可靠）、位置（趋势中继 vs 末端）、持续时间与量能、突破后的回抽确认。窄而长的中枢常为筹码密集/蓄势，突破力度可能大，但更易被单根大 K 穿透、假突破多；且 `GG/DD` 可能远宽于 `ZG/ZD`，只看上下沿会低估真实波动。`ZG==ZD` 是合法极端，不过滤，靠级别与 `is_sure` 区分「精确共识」与「笔划分噪声」。
