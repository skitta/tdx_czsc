# 真机验证清单（Windows x64 + 通达信）

> 适用：P0~P1 各阶段合并后部署的真机回归。部署产物以
> `deploy_to_tdx.bat`（构建当前工作树）为准；验证前**先退出通达信**。

## 0. 前置确认

- [ ] 通达信为 **x64** 版本（本项目 DLL 为 x64）；
- [ ] `D:\new_tdx64\T0002\dlls\dlls.ini` 中 `band1 = tdx_czsc_bridge.dll`
      （公式模板固定用 `TDXDLL1`）；
- [ ] `Ctrl+D → 系统设置 → 设置3` 已勾选
      **“主图指标不影响坐标的高低值”**（否则主图 K 线会被 0 值压缩）；
- [ ] 仓库处于目标分支且工作树干净（`git status`）。

## 1. 构建与冒烟

```powershell
cd E:\DELL\Documents\Codes\tdx_czsc
.\deploy_to_tdx.bat D:\new_tdx64        # 先退出通达信

# 冒烟（普通终端；需先启动服务）
Start-Process .\rust_service\target\release\tdx_czsc_service.exe
.\bridge_dll\build\Release\tdx_czsc_ipc_smoke_test.exe
```

- [ ] 冒烟输出无 `Analyze failed`；配置行显示 `max_bi_num=1000`、
      `analysis_window: 0`（P0c/P1 默认生效的证据）；
- [ ] `.\bridge_dll\build\Release\logs\tdx_czsc_bridge.log` 记录首次请求
      与后续缓存命中。

## 2. 通达信内加载

- [ ] 主图公式：`Ctrl+F → 技术指标公式 → 新建`，导入
      `tdx_formula_examples\main_chart_full.tn6`，属性设为**主图叠加**；
- [ ] 交易系统：新建「交易系统」导入 `buy_sell_expert.tn6` 并叠加
      （B/S 箭头）；类型文字用 `buy_sell_mark.tn6`（技术指标叠加）；
- [ ] 加载后主图出现分型/笔/段/笔中枢/段中枢（首次约 1~2 秒，DLL 自动拉起服务）。

## 3. 功能回归（P0/P0c 核心）

- [ ] **全量覆盖**：缩小视图/滚动到历史深处（2015、2020 年区域），
      笔/段/中枢**全历史连续标注**，无空白区；
- [ ] **笔数完整**：放大早期区域，结构线不中断（笔数不受旧 50 上限截断）；
- [ ] **历史买卖点**：B/S 箭头出现在历史早期（不只最近一年）；
- [ ] 中枢矩形在多处历史区间出现、相邻中枢不重叠；
- [ ] 段中枢（305~307，洋红实线）在 30 分钟周期可见（示例股票 002340 约 3 个），
      与笔中枢（蓝色虚线）区分清晰；`段中枢开关:=0;` 后段中枢消失、笔中枢不变；
- [ ] 服务端未升级时（旧服务端 + 新 DLL）整个快照请求失败而非仅 305~307 为 0
      ——部署顺序必须是**先服务端、后 DLL**；
- [ ] 量能背驰：盘中新 K 线出现后一买/一卖正常（`buy_sell_expert` 内置
      950 量能通道，保持其在 401 之前的调用顺序）。

## 4. P1 性能回归

- [ ] **滚动/缩放零重算**：反复滚动、周期切换无空白等待（快照缓存 +
      增量缓存命中 10µs 级）；可用 `main_chart_full.tn6` 中注释的 903
      通道（最近请求耗时）观察；
- [ ] **多窗口并发**：同时开 2~4 个窗口（不同股票/周期）首刷不长时间
      卡顿（`analysis_parallelism` 默认 4，多标的场景可调大）；
- [ ] 尾盘刷新（新 K 线）流畅：增量承接只演化新增 K 线。

## 6. 常见坑

- deploy 报 `copy failed` → 通达信未退出（DLL 被占用）；
- 加载后完全无显示 → `Ctrl+F → DLL函数` 检查 band1 绑定、重启通达信；
- 专家系统公式报 `TDXSTEPxx` → 绘图函数放错了公式类型（按 README 分工）；
- 通达信装在受保护目录 → 管理员身份运行。
